페이지 메뉴 열기

템플릿 권한 연결하기

데이터 이전을 위해 라이프업 1.3과 1.5 템플릿 모두에 접근 권한을 허용해 주세요.

1

페이지 선택

페이지 선택을 누릅니다.

2

두 라이프업 버전 선택

상단에서 워크스페이스를 선택한 뒤, 하단에서 라이프업 1.3과 라이프업 1.5 버전을 모두 선택합니다.

3

접근 권한 허용

액세스 허용을 누릅니다.

라이프봇 연결 설정

카카오톡 연결하기

카카오톡과 라이프봇을 연결하는 방법입니다.

1

연결 설정 메뉴에서 카카오톡 연결 버튼을 누릅니다.

2

카카오톡 열기 버튼을 누르면 모바일 또는 데스크톱 카카오톡이 열립니다.

3

라이프봇 대화창에 표시된 인증번호를 입력합니다.

4

인증이 완료되면 연결 상태 화면으로 바뀌며, 카카오톡과 라이프봇 연결이 완료됩니다.
