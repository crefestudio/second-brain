라이프업 업데이트는 어떻게 진행되나요?

업데이트는 새로운 라이프업 1.5를 설치한 후, 현재 사용 중인 라이프업 1.3의 데이터를 1.5 버전으로 옮기는 방식으로 진행됩니다.

데이터 이전 과정에서 기존 1.3 템플릿의 데이터가 변경되거나 사라질 수 있기 때문에 업데이트 전에 반드시 백업해주세요.

1
기존 라이프업 1.3 복제하기 현재 사용 중인 라이프업 페이지를 복제하여 백업본을 만들어주세요.
2
라이프업 1.5 설치하기 새로운 라이프업 1.5를 설치해주세요.
⚠️ 반드시 기존 1.3과 같은 워크스페이스에 설치해주세요.
⚠️ 백업은 반드시 해주세요.

데이터 이전 중 문제가 발생할 경우 백업한 1.3 버전을 사용하여 복구할 수 있습니다.

백업하지 않은 상태에서 데이터 이전을 진행하여 발생한 데이터 손실은 복구를 지원하기 어려울 수 있습니다.

데이터 이전 안내

데이터 이전 기능은 현재 시험 운영 중입니다. 이전 과정이나 결과에 대해 궁금한 점이 있으시면 언제든 문의해주세요.

  • 1.3 이전 버전의 페이지 템플릿을 사용한 경우
    데이터 이전 과정에서 경고 메시지가 표시될 수 있습니다. 새 버전의 페이지 템플릿으로 변경하는 과정에서 기존 페이지 템플릿에 직접 작성하거나 수정한 내용은 자동으로 복원되지 않을 수 있습니다.
    경고 메시지가 표시된 경우 백업한 원본을 확인하여 필요한 내용을 직접 복사해주세요.
  • 페이지 템플릿이란?
    페이지를 새로 만들 때 기본으로 생성되는 형식으로, 일종의 속지와 같은 개념입니다.
  • 묶음 할일을 사용한 경우
    할일 관리에서 묶음 할일을 사용하신 경우 기본 템플릿으로 복원될 수 있습니다. 묶음 할일을 사용 중이라면 데이터 이전을 진행하지 마시고 먼저 문의해주세요.
